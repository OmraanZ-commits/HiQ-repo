---
name: Canvas-only task review
description: Why no-code canvas deliverables need a reviewable companion for assigned-task completion
---

For assigned tasks delivered entirely as static canvas shapes, also save a faithful storyboard or presentation document in the workspace before requesting completion review.

**Why:** Task completion review may inspect workspace diffs but cannot verify canvas-only changes outside the working tree. A finished board without a reviewable companion was rejected despite the shapes being present.

**How to apply:** When the user requires no application-code changes, keep the canvas as the visual presentation and add a non-code document that contains the full flow, inputs, conclusions and presenter notes. Do not treat the document as a substitute for the canvas itself.
