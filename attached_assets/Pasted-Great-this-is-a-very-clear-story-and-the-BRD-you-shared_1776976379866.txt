# Replit Instructions

## Integration Monitoring Tab – Frontend Mockup

### 1. Objective

Create a **read‑only Integration Monitoring tab** inside an **Admin Center UI** that allows Admin users to:

*   View **daily ingestion runs**
*   See **success / failure metrics per run**
*   Drill down into **failed records**
*   Monitor **integration health without DB access**

This is a **mock frontend only** using **static JSON or mocked APIs**.

***

### 2. Navigation & Placement

**Navigation path:**

    Admin Center → Integration Monitoring

*   Show this tab **only** if user role = `ADMIN`
*   If role ≠ ADMIN, hide menu item entirely

***

### 3. Screen Layout (High Level)

#### 3.1 Page Header

**Title:**  
`Integration Monitoring`

**Subtext:**  
`Read-only view of ingestion health across source systems`

***

### 3.2 Integration Runs Summary Table

A table that lists **each ingestion run**.

**Columns:**

*   Run Date (YYYY‑MM‑DD)
*   Integration Name
*   Source System
*   Records Received
*   Records Successful
*   Records Failed
*   Run Status (✅ Success | ⚠️ Partial | ❌ Failed)
*   Last Run Timestamp
*   Action → `View Details`

***

### 10. UX Rules (Strict)

✅ Read‑only UI  
✅ No retry buttons  
✅ No edit / update / delete  
✅ No logic inference  
✅ No status recalculation

Add a **note banner** at bottom:

> *All ingestion logic, validation, retries, and audit persistence are handled by backend systems. This screen is for monitoring only.*

***

### 11. Visual Indicators

*   ✅ Success → green
*   ⚠️ Partial → amber
*   ❌ Failed → red

Lifecycle stages should be shown as **labels**, not computed.
