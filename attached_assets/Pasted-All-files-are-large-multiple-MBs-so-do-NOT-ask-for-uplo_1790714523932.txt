Business Rules:

1. Final table grain = one row per customer.
2. Customer determines depot.
3. Vendor comes from Customer + Depot.
4. Join PO Validity using Customer.
5. Join PDP using Customer.
6. Pivot FSSAI Type values (20B, 21B, FDL) into separate columns.
7. Preserve leading zeros for all IDs.
8. If multiple licenses exist for same Customer and Type, choose:
