Design Principles

1. Keep it lightweight.
2. One API for EDI Masters.
3. One API for EDI Conditions.
4. Toggle only changes the dataset being displayed.
5. Search should filter Customer Code.
6. No nested tables.
7. No side panels.
8. No expandable rows.
9. No configuration screen.
10. Mimic an SAP admin lookup screen.
