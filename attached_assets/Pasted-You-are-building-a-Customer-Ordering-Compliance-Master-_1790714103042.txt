OBJECTIVE
Create a single master table with ONE ROW PER CUSTOMER.

1. Customer → Depot Mapping
2. Vendor Code Mapping
3. PO Validity / Lead Time / Rounding Profile
4. PDP Configuration
5. FSSAI License Information

IMPORTANT:
A CUSTOMER CAN HAVE MULTIPLE FSSAI LICENSES.

Typical pattern:

Customer
 ├─ 20B License
 ├─ 21B License
 └─ FDL License

DO NOT CREATE MULTIPLE OUTPUT ROWS.

Instead pivot the FSSAI records into columns.

==================================================================
BUSINESS RULES
==================================================================

Rule 1:
Final output grain = ONE ROW PER CUSTOMER

Rule 2:
Get Depot from Customer_Depot_Mapping.

Rule 3:
Get Vendor Code using:
Customer + Depot

Rule 4:
Join PO Validity using Customer.

Rule 5:
Join PDP using Customer.

Rule 6:
Pivot FSSAI Types into columns:

20B -> 20B License No, 20B Expiry

21B -> 21B License No, 21B Expiry

FDL -> FDL License No, FDL Expiry

Rule 7:
If multiple licenses exist for same customer and same type:

Priority:
1. Lic.status = 'C'
2. Latest End Date

Rule 8:
Preserve leading zeros in all customer codes, license numbers and vendor codes.

Treat all identifiers as TEXT.
